# rosemary-camera

Проект видео-камеры для **Poco M5S** (rosemary, 2207117BPG) и других устройств на **MediaTek Helio G95** (MT6769).

## Главная фишка## Главная фишка

Обычная MIUI камера Xiaomi — только два режима:

| Режим | Разрешение | EIS |
|---|---|---|
| **Стоковая 4K30** | 4K | ❌ Нет стабилизации |
| **Стоковая 1080p30 EIS** | 1080p | ✅ Есть, но урезана |

**Этот проект добавляет:**

| Режим | Разрешение | EIS |
|---|---|---|
| **4K30 EIS (стабильный)** | 4K | ✅ Полная стабилизация без лагов |


Обычная MIUI камера Xiaomi:

| | 4K | EIS | Детали |
|---|---|---|---|
| **Стоковая 4K** | ✅ | ❌ Трясётся | Отличные |
| **Стоковая 1080p30 EIS** | ❌ 1080p | ✅ Но... | Шумодав убивает |

Обычная 1080p30 EIS работает в урезанном режиме — стабилизатор отрубает половину кадра, при движении картинка портится, а шумодав убирает все детали.

**Этот проект** делает 4K30 со стабилизацией EIS без проблем с производительностью, без урезания работы стабилизации.

| | Разрешение | EIS | Стабильность при движении | Шум |
|---|---|---|---|---|
| **Этот проект** | ✅ **4K** | ✅ Полная | ✅ Без лагов и смазов | MFNR (ничего не режется) |

## Специальная сессия камеры

`SessionConfiguration` с тегом **0x8004** (32772 в десятичной системе) — это MTK-специфичный конфиг сессии камеры, без него 4K30 EIS не работает.

```kotlin
val sessionConfig = SessionConfiguration(0x8004)  // 0x8004 = 32772
```

## Другие ключевые параметры:

| Параметр | Значение | Зачем |
|---|---|---|
| `SCALER_CROP_REGION` | `Rect(0, 434, 4624, 3038)` | 4K viewport, EIS без лагов |
| `SessionConfiguration` | `0x8004` (32772) | MTK спец-сессия для EIS |
| `CONTROL_AE_TARGET_FPS_RANGE` | `Range(30, 30)` | Фикс 30fps, HAL не роняет на 20 |
