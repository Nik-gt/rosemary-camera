# rosemary-camera

Проект видео-камеры для **Poco M5S** (rosemary, 2207117BPG) и других устройств на **MediaTek Helio G99** (MT6769V).

## Главная фишка

Обычная MIUI камера Xiaomi:
- **4K без стабилизации (EIS)** — картинка трясётся, но разрешение 4K
- **1080p30 со стабилизацией** — но шумодав убивает детали, а стабилизатор работает в урезанном режиме (качество портится при движении)

**Этот проект** делает 4K30 со стабилизацией EIS без проблем с производительностью, без урезания работы стабилизации. Стабильная картинка без смазов и лагов.

### Хак: SCALER_CROP_REGION

```kotlin
val crop = Rect(0, 434, 4624, 3038)  // 4K viewport OV64B
requestBuilder.set(CaptureRequest.SCALER_CROP_REGION, crop)
```

Камера OV64B снимает с сенсора 4624×3038. Без обрезки EIS-буфер переполняется. `SCALER_CROP_REGION` даёт стабилизатору ровно столько пикселей, сколько ему нужно.

### Специальная сессия камеры

`SessionConfiguration` с тегом **0x8004** (32772 в десятичной системе) — это MTK-специфичный конфиг, без него 4K30 EIS не работает.

```kotlin
val sessionConfig = SessionConfiguration(0x8004)  // 0x8004 = 32772
```

### Почему 4K30 EIS без лагов:

| MIUI стоковая камера | Этот проект |
|---|---|
| 4K **без** EIS — трясётся | ✅ 4K30 **со** EIS — плавно |
| 1080p30 EIS — шумодав убивает детали | ✅ 4K30 EIS — детализация не режется |
| Стабилизатор в 1080p работает в урезанном режиме | ✅ В 4K стабилизатор полные 30fps, без урезания |

### Другие ключевые параметры:

| Параметр | Значение | Зачем |
|---|---|---|
| `SCALER_CROP_REGION` | `Rect(0, 434, 4624, 3038)` | 4K viewport, EIS без лагов |
| `SessionConfiguration` | `0x8004` (32772) | MTK спец-сессия для EIS |
| `CONTROL_AE_TARGET_FPS_RANGE` | `Range(30, 30)` | Фикс 30fps, HAL не роняет на 20 |

## Текущие возможности (v0.1.0 — база)

Пока только 4K30 EIS со стабилизацией. Остальные режимы (Night, зум) добавляются в отдельных ветках.

## Структура проекта

```
app/src/main/java/com/camera/eisenabler/
  MainActivity.kt          — камера, превью, запись
  BackgroundRecordService.kt — фоновая запись (WakeLock + уведомление)
  CameraWidgetProvider.kt   — виджет на домашний экран
```
