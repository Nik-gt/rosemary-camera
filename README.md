# rosemary-camera

Проект видео-камеры для **Poco M5S** (rosemary, 2207117BPG) и других устройств на **MediaTek Helio G95** (MT6769).

## Главная фишка

В системе MIUI 13-14 есть приложение для записи видео MIUI Camera, которое позволяет записывать со стабилизацией только в 1080p30 и электронным EIS. Но электронная стабилизация в этом режиме работает в урезанном варианте — стабилизатор отрубает часть кадра (~20%), при любом движении и повороте телефона 'по' и 'против' часовой стрелки видно, как изображение портится и прямые линии и грани становятся округлыми.

**В проекте** представлено приложении для записи только видео с высоким разрешением 4K30 используя стабилизацию EIS, но в режиме полного кадра.
Full EIS режим позволяет стабилизировать на полном кадре 4624×3038 сенсора OV64B. Так же он работает без проблем с производительностью, которые возникают, если просто без манипуляций включить 4k30 с EIS или 1080p30 EIS в стоковой камере.


## Специальная сессия камеры

`SessionConfiguration` с тегом **0x8004** (32772 в десятичной системе) — это MTK-специфичный конфиг сессии камеры, без него 4K30 EIS не работает.

```kotlin
val sessionConfig = SessionConfiguration(0x8004)  // 0x8004 = 32772
```

## Другие ключевые параметры:

| Параметр | Значение | Зачем |
|---|---|---|
| `SCALER_CROP_REGION` | `Rect(0, 434, 4624, 3038)` | 4K viewport, EIS без лагов |
| `SessionConfiguration` | `0x8004` (32772) | MTK спец-сессия для EIS |
| `CONTROL_AE_TARGET_FPS_RANGE` | `Range(30, 30)` | Фикс 30fps, HAL не роняет на 20 |

## Структура проекта

```
app/src/main/java/com/camera/eisenabler/
  MainActivity.kt          — камера, превью, запись
  BackgroundRecordService.kt — фоновая запись (WakeLock + уведомление)
  CameraWidgetProvider.kt   — виджет на домашний экран
```
